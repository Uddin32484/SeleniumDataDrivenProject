# Claude Selenium Test Automation Project

## Overview
This repository contains a Selenium WebDriver-based test automation framework for testing a sample e-commerce website. It leverages the following tools and technologies:
- **Selenium WebDriver** for browser automation.
- **TestNG** as the test framework.
- **Maven** for dependency management and build automation.
- **ExtentReports** and **Allure** for generating test reports.
- **WebDriverManager** for managing browser drivers.
- **Apache POI** for working with Excel files as test data input.
- **GitHub Actions** for Continuous Integration (CI).

---

## Features
- **Page Object Model (POM)**: Follows POM design principles for maintaining test scripts.
- **Dynamic Configurations**: Supports multiple environments (`prod`, `qa`) via `.properties` files.
- **Data-Driven Testing**: Uses Excel files for parameterized tests.
- **Logging and Reporting**: Outputs detailed test reports with screenshots on failures.
- **Continuous Integration**: Includes GitHub Actions workflows to automate test runs on every push or pull request.
